# IC-7760 Control for Windows

**Download the installer only.** Do not use GitHub's "Source code" zip or tar.gz links — those are not the program.

[Download IC7760Control-Setup-1.4.14.zip](https://github.com/KennyGolubGHub/IC7760Control-Setup/releases/download/v1.4.14/IC7760Control-Setup-1.4.14.zip)

1. Unzip the file.
2. Run **IC7760Control-Setup.exe**.
3. The app runs for **7 days** without a key.
4. Open **Help → Enter license key…**, copy **This PC’s ID**, and email it with your callsign. The key you receive only works on that computer and lasts **one month** from the day you first activate it. Uninstalling and reinstalling does not restart the trial or the month.

This page is a download location. The application source is not published here.

Windows may warn that the app is unrecognized because it is not code-signed.
