# IC-7760 Control for Windows

**Download the installer only.** Do not use GitHub's `Source code` zip or tar.gz links — those are not the program.

[Download IC7760Control-Setup-1.4.20.zip](https://github.com/KennyGolubGHub/IC7760Control-Setup/releases/download/v1.4.20/IC7760Control-Setup-1.4.20.zip)

1. Unzip the file.
2. Run **IC7760Control-Setup.exe**.
3. The app runs for **7 days** without a key. After that, open **Help → Enter license key…** and paste the key you were sent (issued for your callsign or email). The key lasts for the term it was issued with — one month, one year, or lifetime — from the day you first activate it on that PC. Uninstalling and reinstalling does not restart the trial or that term. A lifetime key needs this version.

This page is a download location. The application source is not published here.

Windows may warn that the app is unrecognized because it is not code-signed.
